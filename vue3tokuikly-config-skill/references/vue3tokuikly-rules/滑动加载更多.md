# 滑动加载更多（Vue3 → KuiklyPolyCity）

## Vue3 实现

| 场景 | Vue3 写法 |
|------|-----------|
| 滚动容器触底 | `@scrolltolower` / `onScrollToLower` |
| 列表组件触底 | `onEndReached` |
| Vant 列表 | `<van-list @load="onLoad" :finished="finished" v-model:loading="loading">` |
| 小程序页面触底 | `onReachBottom` |
| 状态位 | `hasMore` / `finished` / `loading` |

## KuiklyPolyCity 实现

Vue 中「滚动列表 + 下拉刷新 + 触底加载」的组合，Kuikly 用 `List` + `Refresh` + `FooterRefresh` 表达：

- 触底加载在 `FooterRefresh` 的 `refreshStateDidChange` 中判断 `FooterRefreshState.REFRESHING` 触发 `loadMore`。
- 列表数据在 `List` 内用 `vforLazy`（或 `vforIndex`）。

```kotlin
List {
    attr { flex(1f); showScrollerIndicator(false) }

    // 下拉刷新头
    Refresh {
        attr { height(70f.px); allCenter() }
        event {
            refreshStateDidChange {
                if (it == RefreshViewState.REFRESHING) ctx.onRefresh()
            }
        }
    }

    // 列表数据
    vforLazy({ ctx.dataList }) { item, index, _ ->
        ItemView { attr { data = item; this.index = index } }
    }

    // 上拉加载更多
    FooterRefresh {
        attr { height(60f.px); allCenter() }
        event {
            refreshStateDidChange {
                if (it == FooterRefreshState.REFRESHING) ctx.loadMore()
            }
        }
    }

    event { scroll { ctx.handleScroll(it.offsetY) } }
}
```

## 注意事项

- `List` 内必须用 `vforLazy` / `vforIndex`，不要用普通 `vfor`。
- `observableList` 批量更新先 `clear()` + `addAll()`，不要循环中逐个 `add`。
- `hasMore` / `finished` 状态对应 Kuikly 的 `FooterRefreshState`（如 `REFRESHING` / `NO_MORE`）。
