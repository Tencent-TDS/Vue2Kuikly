# 基础业务逻辑（Vue3 → KuiklyPolyCity 通用必读）

> 本文档为 `BIZ_BASE_RULES`，所有页面自动加载。覆盖 Vue3（兼容 Vue2）转 KuiklyPolyCity 的核心原则、硬约束、模板与迁移速查。无业务关键字匹配时也须遵循。

## 1. 核心原则

把 Vue 代码翻译为 Kuikly 代码，不做产品优化、不补脑、不基于命名模式创造组件/属性/事件/逻辑。

- **零创造**：Vue 源码没有的 UI、样式、逻辑、接口请求、状态、事件、组件都不要新增。
- **零遗漏**：`data`/`ref`/`reactive`、`props`/`defineProps`、`computed`、`watch`、`methods`/`function`、`setup`、生命周期、`template`、`style`、请求、存储都要逐项迁移。
- **可追溯**：关键代码写 `// 标记来源 xxx.vue 类型: 原始片段`。
- **先学项目**：不确定时先搜索目标 KuiklyPolyCity 工程获取现有用法，再写代码。
- **立即验证**：每个文件迁移完运行可用编译命令，失败就修，不积累错误。

## 2. 项目硬约束（KuiklyPolyCity）

- **页面文件名**：`lucky_draw_machine.vue → LuckyDrawMachine.kt + PageUI.kt`；不要生成 `LuckyDrawMachinePage.kt` / `LuckyDrawMachinePageUI.kt`。
- **页面类**：继承 `BasePager` 时用 `override fun buildBody(): ViewBuilder = buildUI(this)`；**组件**才用 `override fun body()`。
- **页面 UI**：全部写入同目录 `PageUI.kt` 的 `fun buildUI(page: Pager): ViewBuilder`，不要在页面类里写 UI。
- **尺寸**：必须用 `com.tencent.kuiklypolycity.style.px`，如 `width(149f.px)`；例外：`flex(1f)`、`opacity(0.5f)`、`zIndex(10)`、`lines(2)`、`pagerData.pageViewWidth`、`pagerData.statusBarHeight`。
- **`750rpx`**：表示屏幕满宽，迁移为 `pagerData.pageViewWidth`，不要写 `375f.px`。
- **样式语法**：函数调用 `width(100f.px)`，不要 `width = 100f.px`。
- **颜色**：`Color.WHITE` 或 `Color(0xFFFFFFFF)`，不要字符串颜色或 `Color.parseColor()`。
- **协程/JSON**：必须用 Kuikly 版 `com.tencent.kuikly.core.coroutines.*`、`com.tencent.kuikly.core.nvi.serialization.json.JSONObject`；禁止 `kotlinx.coroutines` / `org.json`。
- **类属性实例化自定义对象**：用 `by lazy`，避免 iOS JS 模式初始化问题。
- **`observableList` 批量更新**：先收集临时数组，再 `clear()` + `addAll()`，不要循环中逐个 `add`。
- **`vfor`/`vforIndex`/`vforLazy`**：闭包内必须只有一个根节点；List 内用 `vforIndex`/`vforLazy`，非 List 容器循环渲染用 Kotlin `forEach`。
- **叶子组件**（`Text`/`Image`/`Input` 等）：不支持 `padding*()`，需要内边距用 `margin*()` 或包一层 `View`。
- **历史平台兼容代码**（`isIosForLiteSDK3`/`isAndroidForLiteSDK3` 等）：一律跳过并写注释，不做迁移。
- **定时器**：用 `com.tencent.kuikly.core.timer.Timer`、`by lazy` 声明；页面 `pageWillDestroy()`/`组件 viewDestroyed()` 必须 `cancel()`。
- **事件监听类 Module**（替代 Vue `EventBus`）：注册句柄在页面/组件销毁时必须显式反注册。
- **`suspend` 方法**：必须在 `GlobalScope.launch { ... }`（Kuikly 版）里；禁止 `runBlocking`；点击等回调里也要 `launch` 包一层。

## 3. 页面模板

```kotlin
@Page("page_identifier")
internal class Example : BasePager() {
    // 标记来源 example.vue data/ref: title: ""
    var title by observable(ObservableThreadSafetyMode.NONE, "")

    // 标记来源 example.vue onMounted/created() { this.loadData() }
    override fun created() {
        super.created()
        loadData()
    }

    // 标记来源 example.vue methods: loadData() { ... }
    fun loadData() { /* 业务逻辑 */ }

    override fun buildBody(): ViewBuilder = buildUI(this)
}
```

```kotlin
fun buildUI(page: Pager): ViewBuilder {
    val ctx = page as Example
    return {
        // 标记来源 example.vue template: <div class="page">
        View {
            attr {
                width(ctx.pagerData.pageViewWidth) // 标记来源 example.vue style: width: 750rpx
                flexDirectionColumn()
                backgroundColor(Color.WHITE)
            }
        }
    }
}
```

## 4. 组件模板

```kotlin
internal class ExampleCard : ComposeView<ExampleCardAttr, ExampleCardEvent>() {
    override fun createAttr() = ExampleCardAttr()
    override fun createEvent() = ExampleCardEvent()

    override fun body(): ViewBuilder {
        val ctx = this
        return {
            // 标记来源 example_card.vue template: <div @click="handleClick">
            View {
                attr { width(100f.px); height(50f.px) }
                event { click { ctx.event.onClick?.invoke() } }
            }
        }
    }
}

internal class ExampleCardAttr : ComposeAttr() {
    // 标记来源 example_card.vue props/defineProps: title
    var title by observable(ObservableThreadSafetyMode.NONE, "")
}

internal class ExampleCardEvent : ComposeEvent() {
    // 标记来源 example_card.vue $emit("click")/defineEmits
    var onClick: (() -> Unit)? = null
}
```

## 5. Vue3 ↔ Kuikly 迁移速查

> 上半部分（`<div>`/`v-if`/`setInterval`/协程/请求等）属于 **Kuikly 框架内置能力**，直接按右列写法使用；下半部分（存储/账号/环境/上报/分享等）属于**业务侧原生能力**，Kuikly 框架不提供，必须先在目标工程搜索已有 Module/工具类复用。

| Vue3 | KuiklyPolyCity |
| --- | --- |
| `<div>` | `View` |
| `<span>` / `<p>` | `Text` |
| `<img>` | `Image` |
| `<input>` | `Input` |
| `<textarea>` | `TextArea` |
| `<swiper>` | `SliderPage`（`isHorizontal`、`pageItemWidth/Height`、`loopPlayIntervalTimeMs`、`initSliderItems`、`pageIndexDidChanged`） |
| 富文本混排 | `RichText { attr {...}; Span { ... } }`，多行需 `lines(N)` |
| Lottie/PAG 动画 | `PAG { attr { src(...); repeatCount(N); autoPlay(true) } }` |
| `<list>` + 下拉刷新 + 触底加载 | `List { Refresh { ... }; vforLazy { ... }; FooterRefresh { ... } }` |
| `v-if` | `vif({ condition }) { ... }` |
| `v-for="(item,i) in list"` | `vforIndex({ list }) { item, index -> ... }`（ObservableList） |
| `@click="method"` | `event { click { ctx.method() } }` |
| `this.$emit("hide")` | `event.onHide?.invoke()` |
| `ref(0)` / `reactive({...})` | `observable(ObservableThreadSafetyMode.NONE, value)` / `observableList<T>()` |
| `computed(() => ...)` | `get()` 或 `observable` 派生；需要监听用 `bindValueChange` |
| `watch(x, (nv,ov)=>{...})` | `PagerManager.getCurrentReactiveObserver().bindValueChange(valueBlock = { attr.x }, byOwner = this) { ... }` |
| `async function foo(){ await bar() }` | `fun foo()` 内 `GlobalScope.launch { bar() }`（`bar` 声明 `suspend`） |
| `await xxx()` | `launch { ... }` 内直接调用；回调式 API 用 `suspendCoroutine` 包一层 |
| `Promise.all([a(),b()])` | `listOf(async { a() }, async { b() }).awaitAll()` |
| `setInterval` / `setTimeout` | `Timer().schedule(delay, period) { ... }`，销毁时 `cancel()` |
| `routeEnter` / `route.query.id` | `pagerData.params.optString("id", "")` |
| `comm.smartFetch("KEY")` | `http.smartFetch(KEY, param = param)`，`KEY` 来自 `ReqConfig.kt` |
| `this.$http.get + res 校验` | `http.smartFetchAndCheckRes(KEY, param, useCache = true)` |
| 本地存储 `localStorage.setItem/getItem` | **Kuikly 框架不提供**，先搜索业务 Storage Module（`kv`/`Storage`/`Cache`/`setItem`/`getItem`），复用已有 API；缺失再按 Module 规范新建 |
| 账号/用户信息 | 先搜索项目已有账号 Module/全局扩展；找不到再新建 |
| 运行环境 `process.env` | 先搜索项目已有环境判断能力；缺失再补充 Module |
| 上报 `track/埋点` | 先搜索项目已有上报 Module/工具类，复用实际方法签名 |

## 6. 审计清单要点

- 页面文件是否是 `Xxx.kt + PageUI.kt`，页面类是否用 `buildBody()`；组件是否用 `body()`。
- 所有 Vue 源码元素是否迁移，且没有新增 Vue 源码外内容。
- 组件创建是否来自 `<template>` 真实标签 + `import` + `components` 注册。
- `props`/`defineProps`/`Event`（`$emit`/`defineEmits`）是否只来自组件自身定义。
- 尺寸是否有 `.px`，`750rpx`、状态栏高度、页面宽度是否特殊处理。
- API 是否使用 `ReqConfig.kt` 常量（禁止字符串字面量）。
- 原生能力（存储/账号/环境/分享/上报/事件总线/时间）是否优先搜索项目已有 Module/工具类复用，而非凭空假设符号。
- 时间相关调用是否使用项目内日期工具，禁止 `System.currentTimeMillis()` / `java.util.Date`。
- `observableList` 是否批量 `addAll()`。
- 编译命令是否运行并通过。
