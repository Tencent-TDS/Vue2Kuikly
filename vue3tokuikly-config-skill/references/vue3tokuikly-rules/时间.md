# 时间（Vue3 → KuiklyPolyCity）

## Vue3 实现

| 场景 | Vue3 写法 |
|------|-----------|
| 当前时间戳 | `Date.now()` / `new Date().getTime()` |
| 日期对象 | `new Date()` |
| 年/月/日 | `date.getFullYear()` / `date.getMonth()`（0-11）/ `date.getDate()` / `date.getDay()` |
| 延时/周期 | `setTimeout(fn, ms)` / `setInterval(fn, ms)` / `clearTimeout` / `clearInterval` |
| 日期库 | `moment` / `dayjs` / `date-fns` |

## KuiklyPolyCity 实现

### 定时器（setTimeout / setInterval）

- 一律迁移为 Kuikly 的 `com.tencent.kuikly.core.timer.Timer`：
- `by lazy` 声明；页面 `pageWillDestroy()` / 组件 `viewDestroyed()` 必须 `cancel()`。

```kotlin
import com.tencent.kuikly.core.timer.Timer

private val timer by lazy { Timer() }

// 相当于 setTimeout(fn, 1000)
timer.schedule(delay = 1000, period = 0) { /* 一次性回调 */ }

// 相当于 setInterval(fn, 1000)
timer.schedule(delay = 0, period = 1000) { /* 周期回调 */ }

override fun pageWillDestroy() {
    super.pageWillDestroy()
    timer.cancel()
}
```

### 时间格式化 / 时间戳

- **禁止** `System.currentTimeMillis()`、`java.util.Date`、`kotlinx.datetime` 直接调用。
- 先搜索目标工程的时间工具：关键词 `Date` / `CurrentTime` / `Interval` / `Timestamp` / `getFullYear` / `getMonth` / `getDate`。
- 定位 1~2 个真实调用点，抄类名、方法签名、返回单位（秒 vs 毫秒），一对一映射 Vue 原语义。
- 缺失再按 Module 规范新建业务侧工具或 Module。

## 注意事项

- 不要凭命名假设 `CommDate.getCurrentTimeInMillis()` 等具体调用，以项目实际代码为准。
- `getMonth()` 类方法若沿用 JS 语义（返回 0-11），展示月份需 `+1`；换用别的封装则按其实际语义处理。
- 毫秒 / 秒换算必须根据搜索到的真实返回单位处理，避免差 1000 倍。
