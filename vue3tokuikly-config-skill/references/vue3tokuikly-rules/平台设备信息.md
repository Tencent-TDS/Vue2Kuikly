# 平台设备信息（Vue3 → KuiklyPolyCity）

## Vue3 实现

| 需求 | Vue3 写法 |
|------|-----------|
| 状态栏高度 | 小程序 `wx.getWindowInfo().statusBarHeight`（px）；uni `uni.getSystemInfoSync().statusBarHeight` |
| 导航栏高度 | `wx.getMenuButtonBoundingClientRect()` 计算或固定值；uni 无直接 API，常用常量 |
| 屏幕宽高 | `window.innerWidth` / `window.innerHeight`；小程序 `wx.getWindowInfo().windowWidth` |
| 安全区 | CSS `env(safe-area-inset-top)`；uni `safeAreaInsets.top` |
| 设备信息 | `wx.getDeviceInfo()` / `uni.getSystemInfoSync()` / 5+ `plus.device` |

## KuiklyPolyCity 实现

| 需求 | Kuikly 写法 |
|------|-------------|
| 状态栏高度 | `pagerData.statusBarHeight`（像素值，已是像素，不要再加 `.px`） |
| 导航栏 + 状态栏总高 | `pagerData.statusBarHeight + 44f.px` |
| 屏幕宽度 | `pagerData.pageViewWidth` |
| 安全区 | 先搜索项目 `safeAreaInsets` / 安全区封装，复用现有 API |
| 设备像素比 | 先搜索项目 dpr 工具 |

**Kuikly 示例**
```kotlin
// 状态栏高度（已是像素，不要 .px）
val statusH = ctx.pagerData.statusBarHeight

// 导航栏 + 状态栏
View {
    attr { height(ctx.pagerData.statusBarHeight + 44f.px) }
}
```

## 注意事项

- 不要把 `pagerData.statusBarHeight` 再 `.px` 或除以 2。
- 不要用 `pagerData.navigationBarHeight`（可能不准）；用 `statusBarHeight + 44f.px`。
- 历史平台兼容代码（`isIosForLiteSDK3` / `isAndroidForLiteSDK3` 等）一律跳过并写注释，不做迁移。
- 安全区/设备信息优先搜索目标工程现有封装，缺失再按 Module 规范新建，不要凭命名假设 `DeviceInfo.xxx` 一定存在。
