# 自定义子组件（Vue3 → KuiklyPolyCity）

## Vue3 实现

| 概念 | Vue3 写法 |
|------|-----------|
| 单文件组件 | `.vue`（`<template>` + `<script setup>` + `<style>`） |
| 局部注册 | `components: { XxxCard }` |
| 全局注册 | `app.component('XxxCard', XxxCard)` |
| 入参 | `defineProps(['title'])` / `props: { title: String }` |
| 出参（事件） | `defineEmits(['click'])` / `this.$emit('click', payload)` |
| 组合式 | `setup(props, { emit })` |

## KuiklyPolyCity 实现

Vue 组件 → `ComposeView<Attr, Event>`（页面级用 `BasePager`）。

### 组件创建三条件（必须同时满足）

1. Vue `<template>` 中有 `<component-name>` 标签。
2. Vue `import` 中导入了该组件。
3. Vue `components` 中注册了该组件。

- 只看到 `isShowXxx` / `showXxx` 这类 `data` 布尔值，**不代表**可以创建 `Xxx` 组件。
- `Attr` 只迁移组件自身 `props` / `defineProps`，不要迁移外部传入但组件未定义的属性。
- `Event` 只迁移组件自身 `$emit` / `defineEmits`，没有 emit 就保留空 Event 类。

```kotlin
internal class ExampleCard : ComposeView<ExampleCardAttr, ExampleCardEvent>() {
    override fun createAttr() = ExampleCardAttr()
    override fun createEvent() = ExampleCardEvent()

    override fun body(): ViewBuilder {
        val ctx = this
        return {
            View {
                attr { width(100f.px); height(50f.px) }
                event { click { ctx.event.onClick?.invoke() } }
            }
        }
    }
}

internal class ExampleCardAttr : ComposeAttr() {
    // 对应 defineProps: title
    var title by observable(ObservableThreadSafetyMode.NONE, "")
}

internal class ExampleCardEvent : ComposeEvent() {
    // 对应 defineEmits(['click'])
    var onClick: (() -> Unit)? = null
}
```

### 组件对外扩展函数（可选）

若组件跨包调用或需保持项目现有组件调用风格，可在同文件末尾追加扩展函数：

```kotlin
internal fun ViewContainer<*, *>.MyCard(init: MyCard.() -> Unit) {
    addChild(MyCard(), init)
}
```

无此扩展函数时，同包内也可直接 `MyCard { ... }` 使用；先搜索项目中同类组件是否已按这种风格暴露。

### 组件曝光上报

Vue 在 `onMounted` 里做曝光上报的写法，迁移到 Kuikly 时应写在**根节点的 `didAppear`** 事件里，用一个布尔位防止重复：

```kotlin
private var hasExposed = false

override fun body(): ViewBuilder {
    val ctx = this
    return {
        View {
            attr { /* 布局 */ }
            event {
                didAppear {
                    if (!ctx.hasExposed) {
                        ctx.hasExposed = true
                        // 调用业务侧已有曝光/点击上报方法（先搜索实际签名）
                        <业务上报调用>("eventId", "pageId", biz, actId)
                    }
                }
            }
        }
    }
}
```
